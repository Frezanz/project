# Open Questions and Tests

Update this file whenever the framework encounters an ambiguity, counterexample, unresolved dependency, or competing definition.

## Foundations
- [ ] Define entity without presupposing the relation concept we aim to derive.
- [ ] Determine whether distinction is primitive or relation-derived.
- [ ] Decide whether self-relations and internal relations are admitted.
- [ ] Separate existence, conceptual representation, and reference.

## Relation and measurement
- [ ] State necessary and sufficient conditions for a process to count as measurement in the broad sense.
- [ ] Determine whether all relations are measurable or only relations with specified criteria.
- [ ] Explain how non-numerical measurement differs from description or categorization.
- [ ] Test whether connection can be defined as a special relation and whether measurement can be defined as an operation on relations.

## Truth and perspective
- [ ] Separate expression, proposition, interpretation, and described condition.
- [ ] Define truth relative to an interpretation or model without making it arbitrary.
- [ ] Formalize stability under a set of specified transformations.
- [ ] Find counterexamples to the idea that more stability implies more truth.

## Unification and consistency
- [ ] Identify which terms are primitives and which are derived.
- [ ] Detect circular definitions.
- [ ] Specify the logic used, including how contradictions are handled.
- [ ] Check whether the system is internally consistent within an explicit formalization.
- [ ] Define what “complete” means relative to a language, logic, axioms, and class of questions.
- [ ] Identify empirical claims separately from formal mathematical claims.

## First falsification-oriented tests
1. **Counterexample to identity:** Find cases where a relation exists but no measurement procedure has been defined. Does this refute the claim that relation and measurement are identical, or only a narrow interpretation of measurement?
2. **Ambiguous statement:** Evaluate a sentence with two interpretations. Does the truth vary because the proposition changes, because conditions change, or because an observer's beliefs change?
3. **Stability trap:** Test whether a vague or unfalsifiable claim can appear highly stable without having strong evidence for truth.
4. **Single-item case:** Examine an alleged entity with no external comparison object. Specify whether internal structure or self-relations are allowed before deciding measurability.
5. **Domain transfer:** Take one formal structure from mathematics and identify where it maps well—and where its mapping breaks—in physics, psychology, or ethics.
