# Candidate Primitives

This is a working list, not a settled ontology. A primitive is a concept that the current formalization takes as basic rather than defining using other concepts. We should minimize primitives, but not force everything into one if doing so creates circularity or loses important distinctions.

## Candidates to investigate

### Entity / item
Something treated as a unit of discussion within a model. This definition does not decide whether the entity exists physically, abstractly, fictionally, or only as a representation.

### Distinction
A criterion by which two states, items, descriptions, or cases count as different in a specified framework.

### State / property
A specification of how an entity is characterized at a given point or under a given set of conditions. Whether state and property need to be separate concepts remains open.

### Relation
A specified association among one or more items. We must decide whether relations are primitive, whether they require two or more distinct relata, and whether self-relations are allowed.

### Representation
A sign, sentence, model, image, or mental content that stands for or describes something under an interpretation.

### Proposition
Content that can be evaluated for truth or falsity under a specified semantics or interpretation.

### Observer / perspective
A standpoint characterized by relevant information, context, limitations, or interpretive rules. Whether an observer is necessary for every perspective-dependent relation remains open.

### Transformation
A specified change to a state, model, observer, or context.

### Measurement
To be defined carefully. Candidate meaning: a rule-governed process that characterizes a property or relation by mapping it to a value, category, order, or other interpretable result. This is broader than physical measurement but must remain more precise than merely describing something.

## Candidate distinctions to preserve
- Entity vs representation of an entity
- Sentence vs proposition expressed by that sentence
- Proposition vs truth value
- Relation vs measurement procedure
- Existence vs knowability or measurability
- Observer-relative appearance vs condition-relative truth
- Stability vs truth
- Physical, abstract, fictional, and experiential modes of discussion

## Test for a good primitive set
A candidate foundation should avoid circular definitions, support useful derivations, preserve distinctions needed by examples, and expose counterexamples. We should compare alternative foundations rather than choosing one solely because it sounds universal.
